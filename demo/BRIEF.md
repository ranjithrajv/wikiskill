## Intent

A 30-second no-narration demo video for the WikiSkill OpenCode plugin GitHub repo. Combines three visual styles:

1. **Hook** (0-6s): Bold kinetic typography — "Your agent makes mistakes. WikiSkill remembers."
2. **Architecture** (6-14s): Animated three-layer diagram (Raw → Wiki → Skills) with the evolution loop
3. **Terminal** (14-22s): Simulated /wiki-evolve command output showing pattern discovery and skill creation
4. **Before/After** (22-28s): Side-by-side comparison — same task failing before, succeeding after WikiSkill
5. **CTA** (28-30s): GitHub repo link + paper reference

## Style

- Dark theme (#0a0e14 background)
- JetBrains Mono for code/terminal, Inter for headings
- Purple accent (#6c5ce7) with green/yellow/red semantic colors
- GSAP animations — smooth slides, fades, and pops
- No narration — music bed only (to be added by workflow)

## Customizations

- Terminal scene uses simulated /wiki-evolve output
- Architecture diagram shows the three layers with arrows
- Before/after uses ❌/✅ icons for instant readability
